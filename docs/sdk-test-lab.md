# SDK 实验室

运行 `npm run lab:build`，用静态服务器从 `dist/sdk-test-lab/` 打开 `index.html`。在 B站测试作品中上传 CI 产物内的 `ToyGameKit-SDK-Test-Lab.zip`，用预览和真实宿主分别验证。使用专用测试作品，排行榜和存档写入会改变当前作品数据。

页面提供全部 37 个方法的手动调用，异步接口参数用 JSON 数组传入。事件实时显示并可手动取消。媒体流停止使用时调用 `stopMedia`。导出的记录包括方法、结果类别、耗时及错误码，省略参数和返回数据。

正式页面从 CDN 获取官方 SDK。页面上的版本是本仓库的核对基线，仅用于定位，实时 SDK 没有文档化的版本读取接口。官方 SDK 无法加载时可以手动启用 Mock，结果带有 mode 字段。

实机验证应至少记录客户端版本和平台、预览或正式态、登录或游客、授权允许或拒绝。重点检查容器横竖屏和安全区、播放器监听、摄像头及麦克风、授权和充电回到页面后的事件。预览中的限制需要和正式态分别记录。
